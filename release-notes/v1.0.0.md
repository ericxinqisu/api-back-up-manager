## Vault 1.0.0 — First release

A fully-local API key and backup-code manager for macOS with an Apple-style interface.

### Features
- **Master-password encryption:** AES-256-GCM, key derived with scrypt (N=2¹⁷).
- **API keys:** store, reveal and copy with one click.
- **Backup / 2FA recovery codes:** mark codes used, restore them, copy instantly.
- **Tags & search:** ⌘F to search, ⌘N to add an item.
- **Encrypted export / import:** move your vault between machines as a single `.vault` file.
- **Auto-lock:** locks when idle (configurable) or when the Mac sleeps.
- **100% local:** no network, no accounts, no cloud.
- **Apple design:** frosted-glass sidebar, light/dark mode, custom icon.

### Download
`Vault-1.0.0-arm64-mac.zip` — Apple Silicon. Unzip and drag Vault to Applications.

## Vault 1.1.2 — Touch ID fix

### Fixed
- A successful fingerprint scan was wrongly reported as "Fingerprint not recognized", so Touch ID unlock never completed. It now unlocks as expected.

### Added
- `--touchid-self-test` diagnostic mode for troubleshooting Touch ID.

### Download
`Vault-1.1.2-arm64.dmg` or `Vault-1.1.2-arm64-mac.zip`. Apple Silicon.

The build is not notarized: on first launch, right-click Vault → Open.
